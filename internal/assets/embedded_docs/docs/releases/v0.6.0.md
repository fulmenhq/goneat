# Goneat v0.6.0 — Rust Cooling, Go 1.26.6 CI Runner, and Cloud Bootstrap Hardening

**Release Date**: 2026-09-01
**Status**: Stable (semver-minor: new `dependencies --cooling` Rust capability)

## TL;DR

- **Rust crates.io cooling**: `goneat dependencies` now attaches crates.io publish-age cooling metadata for Rust dependencies
- **CI runner pinned to Go 1.26.6**: container jobs move from `goneat-tools-runner-glibc:v0.5.1` to `:v0.5.4` (fulmen-toolbox v0.5.4), clearing the Go-stdlib HIGH advisory cluster; `go 1.25.0` module floor unchanged
- **Cloud bootstrap hardening**: shellcheck tarball SHA256 verification, advisory tool-pin version compares, pinned bootstrap tool versions
- **MPL-2.0 exception renewed** through 2027-03-31; go-git removal/refactor tracked for a future v0.6.x

## What Changed

### Rust crates.io Cooling (#28)

`goneat dependencies` now queries the crates.io registry for Rust dependencies
and attaches publish-age cooling metadata (`age_days`, `publish_date`) for
registry-sourced crates. Git/path/other-registry crates never inherit a public
crates.io age: they get `age_unknown` plus a `registry_error` marker instead.
Registry query failures are recorded, not fatal.

### CI Runner Pin — Go 1.26.6

`.github/workflows/ci.yml` container jobs use
`ghcr.io/fulmenhq/goneat-tools-runner-glibc:v0.5.4` at all three sites (was
`:v0.5.1`). The v0.5.4 image (fulmen-toolbox) ships Go 1.26.6, clearing the
Go standard-library HIGH advisory cluster carried by every in-runner-built
Go binary, plus node 22.23.2, glibc jq 1.8.2, and the musl openssl 3.5.8-r0
security pins.

The `go 1.25.0` module floor is deliberately unchanged: the CI runner
toolchain and the language-version floor are separate concerns.

### Cloud Bootstrap

- **shellcheck checksum pin**: `scripts/cloud-agent-install.sh` verifies the
  shellcheck v0.11.0 release tarball against arch-specific SHA256 pins
  (x86_64/aarch64) before extraction; checksum failure aborts the shellcheck
  install (warn-only on unsupported architectures).
- **Advisory tool-pin compare**: `ensure_go` compares a best-effort version
  token from the installed tool against its `@vX.Y.Z` pin and WARNs on
  mismatch. Pins are install-time; an already-installed binary is never
  downgraded or replaced, and mismatch never fails the host.
- Bootstrap tool versions are pinned to recommended pins (#31), the
  `GOTOOLCHAIN` pin is raised to `go1.25.8` for gosec (#32), and the
  repository-managed Cursor Cloud Agent dev environment is included (#29).

### MPL-2.0 Exception Renewal

The `filepath-securejoin` exception (transitive via go-git/go-billy) is
renewed through 2027-03-31 with unchanged conditions: unmodified dependency
only, no MPL-covered files vendored or modified. Removal/refactor of the
go-git path is tracked for a future v0.6.x release.

### Lint

`pkg/dependencies/rust_cooling.go` no longer guards `delete` unnecessarily;
`make lint` is clean.

## Upgrading

No consumer-facing contract changes: same CLI, same module floor. CI runners
pick up the Go 1.26.6 toolchain automatically via the retagged image.
